# Provider configuration

Do not commit real API keys.

OpenCode config location on Linux/macOS:

```text
~/.config/opencode/opencode.json
```

- `opencode.alibaba.example.json` follows Alibaba Cloud's documented Coding Plan integration pattern.
- For BytePlus, copy the current values from the official BytePlus **Coding Plan → OpenCode** documentation or console. The provider may change model IDs/endpoints over time, so this kit intentionally does not freeze undocumented values.
